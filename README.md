# 🚲 EcoEntregas - Landing Page (Case 3)

Projeto acadêmico/profissional desenvolvido para a startup **EcoEntregas**, focado em captação de leads e soluções de logística sustentável urbana.

🔗 **Link do Projeto Online:** [https://ecoentregas-oficial.netlify.app](https://ecoentregas-oficial.netlify.app)

---

## 🛠️ Tecnologias e Integrações
- **Frontend:** HTML5, CSS3 (Mobile First, Animações), JavaScript (ES6+).
- **Hospedagem & CDN:** Netlify (com regras de cache e otimização via `_headers`).
- **Captação de Leads:** Formulário assíncrono integrado ao Google Apps Script / Google Sheets.
- **Acessibilidade:** Integration com VLibras.
- **Conformidade LGPD:** Gerenciamento de consentimento de cookies via AdOpt e Política de Privacidade.
- **Métricas:** Google Analytics 4 (GA4).
- **PWA:** Funcionalidades offline e suporte a instalação web (`manifest.json`, `sw.js`).
